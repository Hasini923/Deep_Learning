### Experiment 3 – Convolutional Neural Network (CNN)
Implemented and analyzed the basic components of a CNN and studied how different convolution hyperparameters affect feature maps.

**Topics covered:**
-Convolution operation
-Kernel/filter size
-Feature maps
-Stride and padding
-Max Pooling and Average Pooling
-CNN training and validation performance
-Comparison of different CNN hyperparameters

**Observation:**  
Larger kernels and higher strides reduce feature map dimensions, while Max Pooling performed slightly better than Average Pooling in validation accuracy.
