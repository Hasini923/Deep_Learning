### Experiment 2 – Multi-Layer Perceptron (MLP)
Implemented an MLP using TensorFlow/Keras for multi-class image classification using the Fashion-MNIST dataset.

**Topics covered:**
- Image preprocessing and normalization
- Flattening images
- Dense layers
- ReLU and Softmax activation
- Adam optimizer
- Model training and evaluation
- Hyperparameter optimization using Randomized/Grid Search
