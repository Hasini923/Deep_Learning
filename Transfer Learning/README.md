### Experiment 4 – Transfer Learning
Studied different deep CNN architectures and implemented transfer learning using a pretrained MobileNetV2 model on CIFAR-10.

**Topics covered:**
- LeNet-5
- AlexNet
- VGG16
- GoogleNet/Inception
- ResNet
- Dilated convolution
- Transpose convolution
- Transfer learning
- Fine-tuning
- Pretrained ImageNet models

**Dataset:** CIFAR-10  
- 50,000 training images
- 10,000 testing images
- 10 classes
- Image size: 32 × 32 × 3 :contentReference[oaicite:2]{index=2}

**Result:**  
MobileNetV2 achieved **89.15% testing accuracy** with approximately **2.42 million parameters**. :contentReference[oaicite:3]{index=3}
